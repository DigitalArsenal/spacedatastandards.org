# P3: covariance text

Text. Writer `writeP3(record)` in `lib/js/PROD/covtext.js`; no reader.

## Structure

Eleven lines:

| Line | Content | Tokens | Column | Format |
| --- | --- | --- | --- | --- |
| 1 | version | `VERSION` | 1 | `A80` |
| 2 | state row of the first epoch | `LABEL`, `MSE`, `POSX` .. `VELZ` | as P2 | as P2 |
| 3 | `UVW COVARIANCE MATRIX` | | 1 | |
| 4 | `LOWER TRIANG 6x6 by row:` | | 1 | |
| 5 .. 10 | triangle row k = 1 .. 6 | `COV` | 2 | `%+14.6E` |
| 11 | sigma row | `S1` .. `S6` | 21, 37, 53, 69, 85, 101 | `%+14.6E` |

Line 1 is `PROVENANCE.PRODUCER`. Line 2 equals the first row of P2. Triangle row k is one tab, then the k values of
row k of the lower triangle separated by one blank: value j (from 0) starts at column 2 + 15 j. Line 11 equals the
first row of P4 and line 4 of P1's first epoch block.

## Units, frame, ordering

| Rows, columns | Unit |
| --- | --- |
| 1 .. 3 x 1 .. 3 | km\*\*2 |
| 4 .. 6 x 1 .. 3 | km\*\*2/s |
| 4 .. 6 x 4 .. 6 | km\*\*2/s\*\*2 |
| `S1` .. `S3` | km |
| `S4` .. `S6` | km/s |

The 6 x 6 state block of the first epoch's covariance, in UVW at that epoch's own position and velocity, rows U,
V, W, U-dot, V-dot, W-dot. Parameter rows are not part of P3. Sigmas are the square roots of the UVW diagonal.

## Epoch

The first epoch of the Record; line 2's `MSE` is its minutes from `EPOCH_TZERO`.

## Refusal codes

| Code | Condition |
| --- | --- |
| `record-missing:STATE_DATA` | no states |
| `record-missing:COVARIANCE_DATA` | no covariance |
| `record-missing:PROVENANCE.PRODUCER` | no tool version |
| `field-width:P3.<token>` | a value does not fit its token's field (`field-width:P3.COV` for a triangle value) |
| `field-overlap` | two fields of a line overlap |
| `frame-degenerate` | the first epoch's position and velocity define no UVW frame |
| `cov-size` | the covariance does not have `COV_SIZE` dimension |
