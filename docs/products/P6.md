# P6: covariance message, binary

Binary. Writer `writeP6(record)` (returns a `Uint8Array`) and reader `readP6(bytes)` in
`lib/js/PROD/covmsg-binary.js`.

## Layout

Byte order: little-endian for every field.

Framing: the message is a sequence of records and nothing else. A record is a 4-byte unsigned byte count N, N
payload bytes, and the same 4-byte count again. No byte precedes the first record or follows the last.

| Record | Payload bytes | Content |
| --- | --- | --- |
| 1, header | 20 | `EPOCH`, `COV_SIZE`, `WTD_RMS` |
| 2, state block | 168 | the 21 lower-triangle values of rows 1 to 6, row by row, float64 |
| 3 .. | 8 k | row k = 7 .. `COV_SIZE`: its k lower-triangle values, float64 |

Header payload:

| Offset | Type | Field | Value |
| --- | --- | --- | --- |
| 0 | float64 | `EPOCH` | UTC milliseconds since 1970-01-01T00:00:00Z, leap seconds not counted: the first epoch |
| 8 | int32 | `COV_SIZE` | 6 plus the number of solved parameters, 6 to 11 |
| 12 | float64 | `WTD_RMS` | the fit's `WEIGHTED_RMS` |

A message of `COV_SIZE` n is 28 + 176 + the sum over k = 7 .. n of (8 + 8k) bytes.

## Units, frame, ordering, epoch

The first epoch's covariance. The state block (rows 1 to 6) is in UVW at the first epoch's own position and
velocity: km\*\*2, km\*\*2/s, km\*\*2/s\*\*2. Parameter rows are positional, in the fixed order of the solved
parameters (`DRAG_AREA_OVER_MASS`, `DRAG_AREA_OVER_MASS_RATE`, `SRP_AREA_OVER_MASS`, `IN_TRACK_ACCELERATION`,
`OUTGASSING_ACCELERATION`): row 7 is the first solved, row 8 the second. The message does not name them; their
values are unchanged, in the parameters' own units. Epoch: `EPOCH`, the first state's instant.

## Reader

`readP6(bytes)` returns `{ epochMs, covSize, weightedRms, ltm }`, `ltm` the lower triangle of dimension `covSize`
row by row (the UVW state block, then the parameter rows). It refuses any deviation from the layout.

## Refusal codes

| Code | Condition |
| --- | --- |
| `record-missing:STATE_DATA` | no state |
| `record-missing:COVARIANCE_DATA` | no covariance |
| `record-missing:WEIGHTED_RMS` | no weighted RMS |
| `p6-cov-size` | `COV_SIZE` outside 6 to 11 |
| `p6-not-finite:<field>` | a value that is not finite (`p6-not-finite:EPOCH`, `p6-not-finite:WTD_RMS`, `p6-not-finite:COV`, or a row on reading) |
| `p6-framing` | a count that is short, missing or unequal to its trailing copy |
| `p6-header-width` | a header record that is not 20 bytes |
| `p6-row-width:<row>` | a row record missing or of the wrong length |
| `p6-trailing` | bytes after the last row |
| `frame-degenerate` | the first epoch's position and velocity define no UVW frame |
| `cov-size` | the covariance does not have `COV_SIZE` dimension |
