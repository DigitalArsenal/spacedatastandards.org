# P4: sigma text

Text. Writer `writeP4(record)` in `lib/js/PROD/covtext.js`; no reader.

## Structure

A version line, then one sigma row per epoch.

| Line | Token | Column | Format | Unit | Value |
| --- | --- | --- | --- | --- | --- |
| 1 | `VERSION` | 1 | `A80` | | `PROVENANCE.PRODUCER` |
| 2 .. | `S1`, `S2`, `S3` | 21, 37, 53 | `%+14.6E` | km | U, V, W position sigmas |
| 2 .. | `S4`, `S5`, `S6` | 69, 85, 101 | `%+14.6E` | km/s | U, V, W velocity sigmas |

Row i equals line 4 of P1 epoch i; row 0 equals line 11 of P3.

## Frame, ordering, epoch

Each sigma is the square root of the diagonal of that epoch's covariance state block in UVW at that epoch's own
position and velocity. No scale factor. Rows in Record epoch order, one per epoch; P4 prints no epoch.

## Refusal codes

| Code | Condition |
| --- | --- |
| `record-missing:STATE_DATA` | no states |
| `record-missing:COVARIANCE_DATA` | no covariance |
| `record-missing:PROVENANCE.PRODUCER` | no tool version |
| `field-width:P4.<token>` | a value does not fit its token's field |
| `field-overlap` | two fields of a line overlap |
| `frame-degenerate` | an epoch's position and velocity define no UVW frame |
| `cov-size` | the covariance does not have `COV_SIZE` dimension |
