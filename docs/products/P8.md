# P8: state-transition-matrix ephemeris

Text. Writer `stmEphemerisText(record)` in `lib/js/PROD/stmephemeris.js`; `stmEphemeris(record)` returns the same
content unprinted. Writer only: the codec has no P8 reader.

## Input

A Record built with sensitivities: `fromOcm(ocm, odr, sensitivities)` with one `$PRW` state matrix per epoch,
Phi(t, t0), row-major, `DIMENSION` equal to `COV_SIZE`: d(row quantity at t) / d(column quantity at t0), t0 the
first state, over the six cartesian state rows and then the solved parameters in `COV_PARAMETERS` order. Without
sensitivities P8 is refused `sensitivities-missing`.

## Content

J(t) = [Phi_ss(t, t0) J_eq | Phi_sp(t, t0)], a 6 x `COV_SIZE` matrix, with J_eq = d(cartesian)/d(a, af, ag, L, chi,
psi) analytic at the first state's equinoctial set. The header covariance is the first state's covariance over
those elements and the solved parameters, P_eq = T^-1 P(t0) T^-T with T = blockdiag(J_eq, I). The cartesian
covariance at each epoch is J_full(t) P_eq J_full(t)^T with J_full = [J(t); 0 I].

## Structure

| Lines | Tokens | Column | Format | Value |
| --- | --- | --- | --- | --- |
| 1 | `EPOCH` | 2 | `S18` | `EPOCH_TZERO`, the first state's epoch |
| 1 | `WTD_RMS` | 21 | `%+14.6E` | the fit's `WEIGHTED_RMS` |
| 2 .. `COV_SIZE` + 1 | `COV` | 2 | `%+14.6E` | row i of P_eq's lower triangle: one tab, then i values separated by one blank |
| per epoch, 6 lines | `MSE` | 16 | `F12.6` | minutes from the epoch |
| per epoch, 6 lines | `SENS1` .. `SENS6` | 32, 48, 64, 80, 96, 112 | `%+14.6E` | row x, y, z, vx, vy, vz of J(t): d(row)/d(a, af, ag, L, chi, psi) |
| per epoch, 6 more lines when parameters are solved | `MSE`, `SENS1` .. | as above | as above | the same rows: d(row)/d(parameter), one column per solved parameter in `COV_PARAMETERS` order |

Every line ends with a line feed.

## Units, frame, ordering, epoch

Units: km, km/s, deg (L), and the parameters' units; P_eq in the products of its rows' units; sensitivities in row
units per column unit. Frame: the cartesian rows are the Record's trajectory frame; the covariance frame must be
that frame and its type `CARTPV`. Ordering: equinoctial rows a, af, ag, L, chi, psi, then the solved parameters in
the fixed order; epochs in Record order, the first at `EPOCH_TZERO`.

## Refusal codes

| Code | Condition |
| --- | --- |
| `sensitivities-missing` | the Record carries no state transition matrices |
| `record-missing:STATE_DATA` | no states |
| `record-missing:COVARIANCE_DATA` | no covariance |
| `record-missing:GM` | no `PERTURBATIONS.GM` |
| `record-missing:WEIGHTED_RMS` | no weighted RMS |
| `cov-type:<type>` | a covariance type other than `CARTPV` |
| `cov-frame:<frame>` | a covariance frame other than the trajectory frame |
| `epoch-origin` | the first state is not at `EPOCH_TZERO` |
| `stm-shape` | a matrix that is not `COV_SIZE` x `COV_SIZE`, or a count that is not one per epoch |
| `field-overflow:<token>` | a value that does not fit its field |
| `field-overlap` | two fields of a line overlap |
| `frame-degenerate` | the first state defines no orbit plane |
| `frame-unbound` | the first state is not an ellipse |
| `frame-eccentricity` | eccentricity not below one |
| `frame-singular` | a singular Jacobian |

(`COV_SIZE` 8), chosen state transition matrices with identity parameter rows, each epoch's covariance their
