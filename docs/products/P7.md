# P7: element set

Text, two forms, produced on demand from the Record. Writers `elsetTwoLine(record)` and
`elsetElementFile(record)` in `lib/js/PROD/elset.js`. Writer only: the codec has no P7 reader.

## Two-line form

Two lines of 69 characters, each ending with a line feed. The form carries the Record's mean element set only when
its `MEAN_ELEMENT_THEORY` is `SGP4`; any other theory, or a Record without a mean element set, is refused
`theory-not-exportable:<THEORY>` (the set's theory, else the Record's theory, else `UNSPECIFIED`). No element of
another theory is converted.

Line 1:

| Token | Column | Width | Value |
| --- | --- | --- | --- |
| `TLE1_LINE_NUMBER` | 1 | 1 | `1` |
| `TLE1_CATALOG_NUMBER` | 3 | 5 | `NORAD_CAT_ID`, five digits, leading zeros; 1 to 99999 |
| `TLE1_CLASSIFICATION` | 8 | 1 | `HEADER.CLASSIFICATION` when one character; `U` when absent |
| `TLE1_INTERNATIONAL_DESIGNATOR` | 10 | 8 | `INTERNATIONAL_DESIGNATOR` `YYYY-NNNP[PP]` as `YYNNNP[PP]`, left-justified; blank when absent |
| `TLE1_EPOCH_YEAR` | 19 | 2 | the set's epoch year, two digits (pivot 57: 1957 to 2056) |
| `TLE1_EPOCH_DAY` | 21 | 12 | day of year with eight decimals, `DDD.DDDDDDDD`, rounded once on a 1e-8 day grid |
| `TLE1_MEAN_MOTION_DOT` | 34 | 10 | sign (blank or `-`) then `.DDDDDDDD`; magnitude below 1 |
| `TLE1_MEAN_MOTION_DDOT` | 45 | 8 | sign, five digits with an assumed leading point, exponent sign and digit |
| `TLE1_BSTAR` | 54 | 8 | B\*, 1/Earth radii, as `TLE1_MEAN_MOTION_DDOT` |
| `TLE1_EPHEMERIS_TYPE` | 63 | 1 | `0` |
| `TLE1_ELEMENT_SET_NUMBER` | 65 | 4 | blank |
| `TLE1_CHECKSUM` | 69 | 1 | checksum of columns 1 to 68 |

Line 2:

| Token | Column | Width | Value |
| --- | --- | --- | --- |
| `TLE2_LINE_NUMBER` | 1 | 1 | `2` |
| `TLE2_CATALOG_NUMBER` | 3 | 5 | as line 1 |
| `TLE2_INCLINATION` | 9 | 8 | `F8.4` deg, 0 to 180 |
| `TLE2_RA_OF_ASC_NODE` | 18 | 8 | `F8.4` deg, 0 to below 360 |
| `TLE2_ECCENTRICITY` | 27 | 7 | seven digits, assumed leading point; below 1 |
| `TLE2_ARG_OF_PERICENTER` | 35 | 8 | `F8.4` deg, 0 to below 360 |
| `TLE2_MEAN_ANOMALY` | 44 | 8 | `F8.4` deg, 0 to below 360 |
| `TLE2_MEAN_MOTION` | 53 | 11 | `F11.8` rev/day (Kozai, as the set defines it) |
| `TLE2_REV_AT_EPOCH` | 64 | 5 | `ORB_REVNUM` modulo 100000, right-justified, when the set's epoch is `EPOCH_TZERO`; blank otherwise |
| `TLE2_CHECKSUM` | 69 | 1 | checksum of columns 1 to 68 |

Exponent fields (`TLE1_MEAN_MOTION_DDOT`, `TLE1_BSTAR`): 0.DDDDD x 10^e with e from -9 to 9; zero prints
`00000+0`; a magnitude below 0.000005e-9 prints zero; above 0.99999e9 is refused. Checksum: the sum of the digits of
columns 1 to 68, each `-` counting one, modulo 10.

Epoch: the mean element set's `EPOCH`, UTC. Frame: the mean element set's own.

## Element-file form

One line ending with a line feed: the `$OCM` `EQUINOCTIAL` set of the Record's first state under the Record's GM,
then the parameters `OD_DYNAMIC_PARAMETERS` carries, solved for or held.

| Token | Column | Format | Unit | Value |
| --- | --- | --- | --- | --- |
| `ELF_EPOCH` | 2 | `S18` | UTC | the first state's epoch |
| `ELF_SEMI_MAJOR_AXIS` | 21 | `F15.6` | km | a |
| `ELF_AF` | 37 | `F15.10` | | af |
| `ELF_AG` | 53 | `F15.10` | | ag |
| `ELF_MEAN_LONGITUDE` | 69 | `F15.8` | deg | L |
| `ELF_CHI` | 85 | `F15.10` | | chi |
| `ELF_PSI` | 101 | `F15.10` | | psi |
| `ELF_RETROGRADE_FACTOR` | 117 | `I3` | | fr |
| `ELF_B` | 121 | `%+14.6E` | m\*\*2/kg | `DRAG_AREA_OVER_MASS` |
| `ELF_BDOT` | 137 | `%+14.6E` | m\*\*2/kg/s | `DRAG_AREA_OVER_MASS_RATE` |
| `ELF_AGOM` | 153 | `%+14.6E` | m\*\*2/kg | `SRP_AREA_OVER_MASS` |
| `ELF_T` | 169 | `%+14.6E` | m/s\*\*2 | `IN_TRACK_ACCELERATION` |
| `ELF_OUTGASSING` | 185 | `%+14.6E` | km/s\*\*2 | `OUTGASSING_ACCELERATION` |

A parameter the Record does not carry leaves its columns blank. Frame: the equinoctial set of the trajectory
frame's state. Ordering: the `$OCM` `EQUINOCTIAL` order, then the parameters in the fixed order.

## Refusal codes

| Code | Condition |
| --- | --- |
| `theory-not-exportable:<THEORY>` | two-line form of a set that is not `SGP4`, or no mean element set |
| `record-missing:NORAD_CAT_ID` | two-line form without a catalog number |
| `record-missing:STATE_DATA` | element-file form without a state |
| `record-missing:GM` | element-file form without `PERTURBATIONS.GM` |
| `epoch-form:MEAN_ELEMENTS.EPOCH` | the set's epoch is not an ISO 8601 instant |
| `field-form:<token>` | a value not in its field's form (`field-form:TLE1_INTERNATIONAL_DESIGNATOR`) |
| `field-range:<token>` | an angle or the eccentricity outside its range (`field-range:TLE2_ECCENTRICITY`) |
| `field-overflow:<token>` | a value that does not fit its field (`field-overflow:TLE1_CATALOG_NUMBER`, `field-overflow:TLE1_EPOCH_YEAR`, `field-overflow:TLE2_MEAN_MOTION`) |
| `field-overlap` | a line runs past its field layout |
| `frame-degenerate` | the first state defines no orbit plane |
| `frame-unbound` | the first state is not an ellipse |
| `frame-eccentricity` | eccentricity not below one |
