# P5: covariance message, text

Text. Writer `writeP5(record)` and reader `readP5(text, gm)` in `lib/js/PROD/covmsg-text.js`.

## Structure

One tag per line, `KEY = value`, each line ending with a line feed. The value is the tag's format with its
leading and trailing blanks removed; the format's width still bounds it. Tags appear in the order below; a tag
whose Record value is absent is not written. The covariance section closes the message: `ELSET`, `COV_SIZE`,
`COV_PARAMETERS`, `WTD_RMS`, then one `COV` line per lower-triangle row, row k holding k values separated by one
blank.

| Tag | Format | Unit | Value |
| --- | --- | --- | --- |
| `EPOCH` | `S18` | UTC | the first epoch |
| `REV` | `I8` | | the first epoch's revolution number |
| `J2K_POS_X`, `_Y`, `_Z` | `%+.15E` | km | the first state when the trajectory frame is EME2000 |
| `J2K_VEL_X`, `_Y`, `_Z` | `%+.15E` | km/s | as above |
| `ECI_POS_X`, `_Y`, `_Z` | `%+.15E` | km | the first state when the trajectory frame is TEME |
| `ECI_VEL_X`, `_Y`, `_Z` | `%+.15E` | km/s | as above |
| `EFG_POS_X`, `_Y`, `_Z` | `%+.15E` | km | the first state when the trajectory frame is ITRF |
| `EFG_VEL_X`, `_Y`, `_Z` | `%+.15E` | km/s | as above |
| `GEOPOTENTIAL` | `A16` | | `PERTURBATIONS.GRAVITY_MODEL` |
| `DRAG_MODEL` | `A16` | | `PERTURBATIONS.ATMOSPHERIC_DRAG` |
| `LUNISOLAR` | `L1` | | `Y` when `N_BODY_PERTURBATIONS` names `MOON` or `SUN` |
| `SRP` | `L1` | | `Y` when `SOLAR_RAD_PRESSURE` is stated |
| `TIDES` | `L1` | | `Y` when `SOLID_TIDES_MODEL` or `OCEAN_TIDES_MODEL` is stated |
| `IN_TRACK_THRUST` | `L1` | | `Y` when the Record carries `IN_TRACK_ACCELERATION` |
| `B` | `%+.15E` | m\*\*2/kg | `DRAG_AREA_OVER_MASS` |
| `BDOT` | `%+.15E` | m\*\*2/kg/s | `DRAG_AREA_OVER_MASS_RATE` |
| `SRP_COEFF` | `%+.15E` | m\*\*2/kg | `SRP_AREA_OVER_MASS` |
| `EDR` | `%+.15E` | W/kg | the fit's `SEDR` |
| `THRUST_ACCEL` | `%+.15E` | m/s\*\*2 | `IN_TRACK_ACCELERATION` |
| `CM_OFFSET` | `%+.15E` | km | never written |
| `OUTGASSING` | `%+.15E` | km/s\*\*2 | `OUTGASSING_ACCELERATION` |
| `F10_OBS`, `F10_AVG`, `AP_AVG` | `%+.15E` | as the `$OCM` | `FIXED_F10P7`, `FIXED_F10P7_MEAN`, `FIXED_GEOMAG_AP` when not zero |
| `TAI_UTC`, `UT1_UTC` | `%+.15E` | s | at the epoch |
| `UT1_RATE` | `%+.15E` | s/day | never written |
| `POLAR_X`, `POLAR_Y` | `%+.15E` | arcsec | never written |
| `NUTATION` | `A16` | | `PERTURBATIONS.REDUCTION_THEORY` |
| `LEAP_SECOND` | `I4` | s | `NEXT_LEAP_TAIMUTC` |
| `INTEGRATOR_MODE`, `COORD_SYS`, `PARTIALS`, `STEP_MODE` | `A16` | | the `INTEGRATOR` enum names; not written when unspecified |
| `INITIAL_STEP` | `%+.15E` | s | `INTEGRATOR.INITIAL_STEP_SECONDS` |
| `ERROR_CONTROL` | `%+.15E` | | `INTEGRATOR.ERROR_CONTROL` |
| `SIGMA_U`, `SIGMA_V`, `SIGMA_W` | `%+.15E` | km | UVW position sigmas of the first epoch |
| `SIGMA_UD`, `SIGMA_VD`, `SIGMA_WD` | `%+.15E` | km/s | UVW velocity sigmas of the first epoch |
| `ELSET` | `A16` | | `EQUINOCTIAL` |
| `COV_SIZE` | `I3` | | 6 plus the number of solved parameters |
| `COV_PARAMETERS` | `A128` | | the solved parameters' names, blank-separated, in the fixed order; not written when none is solved |
| `WTD_RMS` | `%+.15E` | | the fit's `WEIGHTED_RMS` |
| `COV` | `%+.15E` | see below | one lower-triangle row per line |

Every tag above is a row of the `tokens` P5 table, in its order. `COV_PARAMETERS` names the parameter rows 7 to
`COV_SIZE`.

Required: `EPOCH`, one complete state triple, `ELSET`, `COV_SIZE`, `WTD_RMS` and the `COV` rows.

## Frame

The state triple is the Record's trajectory frame: `J2K` is EME2000, `ECI` is TEME, `EFG` is ITRF. P5 has no triple
for any other frame: a GCRF Record is refused with `p5-frame:<name>`. The codec does no frame transformation.

The covariance (`ELSET = EQUINOCTIAL`) is the first epoch's covariance with the state block in the `$OCM`
`EQUINOCTIAL` set at the first state's own elements: rows a (km), af, ag, L (deg), chi, psi, then the parameter
rows unchanged in their own units. The sigma tags are UVW.

## Ordering, epoch

Covariance rows: the six equinoctial rows, then the solved parameters in the fixed order. Epoch: the first state's
instant, UTC calendar form.

## Reader

`readP5(text, gm)` returns a Record. `gm` (km\*\*3/s\*\*2) is an argument: P5 states no GM, and the equinoctial block
converts to the Record's cartesian block through it. The reader takes `TIME_SYSTEM` as UTC; a `Y` for `SRP` or
`TIDES` reads back as the model `UNSPECIFIED`; `LUNISOLAR = Y` reads back as `MOON` and `SUN`. It refuses an
unknown tag, a tag out of order or repeated, a malformed value and a covariance that does not fit `COV_SIZE`.

Round trip: `writeP5(readP5(text, gm))` returns the same tags in the same order; tags, flags and values that are not
transformed are byte-identical; `COV` and sigma values agree within 1e-12 relative, the covariance being
equinoctial in P5 and cartesian in the Record.

## Refusal codes

| Code | Condition |
| --- | --- |
| `record-missing:STATE_DATA` | no state |
| `record-missing:TRAJ_REF_FRAME` | no trajectory frame |
| `record-missing:COVARIANCE_DATA` | no covariance |
| `record-missing:WEIGHTED_RMS` | no weighted RMS |
| `record-missing:GM` | no GM in the Record, or `gm` not positive on reading |
| `p5-frame:<name>` | a trajectory frame other than EME2000, TEME or ITRF |
| `p5-field:<tag>` | a value does not fit its tag's format (`p5-field:COV` for a covariance value) |
| `p5-line:<n>` | line n is not `KEY = value` |
| `p5-unknown-tag:<tag>` | a tag that is not a P5 tag |
| `p5-tag-order:<tag>` | a tag out of order or repeated |
| `p5-missing:<tag>` | a required tag is absent, or a solved parameter's value tag is absent |
| `p5-value:<tag>` | a value that is not its tag's format |
| `p5-elset:<value>` | `ELSET` other than `EQUINOCTIAL` |
| `p5-cov-row:<row>` | a `COV` row missing or with the wrong number of values |
| `p5-flag:IN_TRACK_THRUST` | `IN_TRACK_THRUST` is not `Y` exactly when `THRUST_ACCEL` is stated |
| `p5-state` | not exactly one complete state triple |
| `parameter-unknown:<name>` | `COV_PARAMETERS` names an unknown parameter |
| `cov-size` | `COV_SIZE` is not 6 plus the `COV_PARAMETERS` count |
| `calendar-form` | `EPOCH` is not the calendar form |
| `calendar-day-of-year` | `EPOCH` day outside the year |
| `calendar-day-366` | `EPOCH` day 366 in a year that is not a leap year |
| `calendar-time-range` | `EPOCH` time out of range |
| `calendar-leap-second` | `EPOCH` in a leap second |
| `frame-degenerate` | the state defines no orbit plane or UVW frame |
| `frame-unbound` | the state is not an ellipse |
| `frame-eccentricity` | eccentricity not below one |
| `frame-singular` | a singular Jacobian |

The reader's Record passes through `fromOcm`; its codes are on the [README](README.md).
