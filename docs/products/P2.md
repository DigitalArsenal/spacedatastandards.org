# P2: state rows

Text. Writer `writeP2(record)` or `writeP2([record, ...])` and reader `readP2(text)` in
`lib/js/PROD/staterow.js`; `writeStateRows(groups)` writes rows read back by `readP2`.

## Structure

One header line, then one group of rows per Record, in the order given; one blank line between two groups. A
group holds one row per epoch of its Record.

Header line: each token's name at its field, `LABEL` starting at its start column, every other name ending at its
token's last column.

| Token | Column | Format | Unit | Value |
| --- | --- | --- | --- | --- |
| `LABEL` | 3 | `A6` | | `NLEXYZ` |
| `MSE` | 16 | `F12.6` | min | minutes from `EPOCH_TZERO` |
| `POSX`, `POSY`, `POSZ` | 32, 50, 65 | `F15.8` | km | position |
| `VELX`, `VELY`, `VELZ` | 81, 97, 113 | `F16.9` | km/s | velocity |

Row i of a group equals line 1 of P1 epoch i (with the label) and, for i = 0, line 2 of P3.

`POSZ` starts at column 65, the column after `POSY`'s last; a `POSZ` that fills its 15 columns leaves no blank
between the two fields. `VELX`, `VELY` and `VELZ` are adjacent the same way. The reader reads by column.

## Frame, ordering, epoch

Cartesian position and velocity in the Record's trajectory frame (`TRAJ_REF_FRAME`); P2 does not state the
frame. Rows in Record epoch order. Epoch: minutes from the Record's `EPOCH_TZERO`.

## Reader

`readP2(text)` returns `{ groups }`, each group a list of `{ minutes, state }`. Values are those printed: positions
to 5e-9 km, velocities to 5e-10 km/s. For a text `writeP2` wrote,
`writeStateRows(readP2(text).groups)` returns it byte for byte.

## Refusal codes

| Code | Condition |
| --- | --- |
| `record-missing:STATE_DATA` | a Record or a group without states |
| `field-width:P2.<token>` | a value does not fit its token's field |
| `field-overlap` | two fields of a line overlap |
| `p2-empty` | the text does not end with a line feed, or holds no rows |
| `p2-header` | the first line is not the P2 header |
| `p2-row:<line>` | line `<line>` is not a P2 row, a field is not a number, or a group is empty |
