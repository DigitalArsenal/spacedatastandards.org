# P9: residual listing

Text. Writer `writeP9(record)` and reader `readP9(text)` in `lib/js/PROD/residual.js`; `writeResidualRows(rows)`
writes rows read back by `readP9`.

## Input

The Record's residuals: the `$ODR` given to `fromOcm` as its second argument, its `EDITED_OBSERVATIONS` in order,
one per input the fit used. A fit without per-input residuals yields no `$ODR` rows and P9 is refused
`record-missing:EDITED_OBSERVATIONS`.

## Structure

Line 1 is the sign convention `RESIDUAL = OBSERVED - COMPUTED`; no column-name line. Then one row per input:

| Token | Column | Format | Value |
| --- | --- | --- | --- |
| `ID` | 2 | `A24` | `OBSERVATION_ID` |
| `EPOCH` | 27 | `S18` | `EPOCH`, UTC |
| `TYPE` | 46 | `A12` | `OBSERVATION_TYPE`, its enum name |
| `OBSERVED` | 59 | `%+14.6E` | `OBSERVED_VALUE` |
| `COMPUTED` | 74 | `%+14.6E` | `COMPUTED_VALUE` |
| `RESIDUAL` | 89 | `%+14.6E` | `OBSERVED_VALUE` minus `COMPUTED_VALUE` |
| `WEIGHT` | 104 | `%+14.6E` | `WEIGHT` |
| `ACCEPTED` | 119 | `L1` | `ACCEPTED` |
| `CODE` | 121 | `A8` | `PERTURBATION_MODEL_CODE` |

Lines end with a line feed; trailing blanks are trimmed.

`TYPE` holds 12 characters. Seven of the 22 observation type names fit: `UNSPECIFIED`, `RANGE`, `RANGE_RATE`,
`DOPPLER`, `RELAY_RANGE`, `SKIN_RANGE`, `LASER_RANGE`. Every other name, `RIGHT_ASCENSION_DECLINATION` and
`AZIMUTH_ELEVATION` among them, is refused `field-width:P9.TYPE`; a name is never cut.

## Units, frame, ordering, epoch

`OBSERVED`, `COMPUTED` and `RESIDUAL` are in the observation type's own unit, as the `$ODR` states them; `WEIGHT`
as the `$ODR` states it. No frame. Rows in `$ODR` order. Epoch: each input's UTC epoch in the calendar form.

## Reader

`readP9(text)` returns `{ rows }`, each row `{ id, epochMs, type, typeName, observed, computed, residual, weight,
accepted, code }`. For a text `writeP9` wrote, `writeResidualRows(readP9(text).rows)` returns it byte for byte.

## Refusal codes

| Code | Condition |
| --- | --- |
| `record-missing:EDITED_OBSERVATIONS` | the Record carries no residuals |
| `record-missing:EDITED_OBSERVATIONS[<i>].EPOCH` | input i states no epoch |
| `record-missing:EDITED_OBSERVATIONS[<i>].PERTURBATION_MODEL_CODE` | input i states no perturbation-model code |
| `field-width:P9.<token>` | a value does not fit its field (`field-width:P9.TYPE` for a type name over 12 characters) |
| `field-overlap` | two fields of a line overlap |
| `p9-empty` | the text does not end with a line feed, or holds no rows |
| `p9-header` | the first line is not the sign convention |
| `p9-row:<line>` | line `<line>` is not a P9 row: its length, epoch, number fields or accepted flag |
| `p9-type:<line>` | line `<line>` names no observation type |
