# CLG validation requirements

These are serialization and native implementation acceptance requirements. A schema round trip does not establish physical correctness.

## 3. Fixed reference cases and assertions

Unless overridden, use same-body SIMULTANEOUS, requested total accuracy **1 s**, root tolerance 0.00025 s, isolation floor 1e-9 s, range extremum tolerance 0.001 m, ALL_DIRECTIONS, ELECTRONIC with explicit zero switch time, duplex COMMON_AXIS with explicit zero separation allowance, finite range [1,1e8] m, no blackouts, one independent slot. Model floor is ≥0.3335641 s, so the 1 s accuracy is honest only if the full discrepancy certificate fits; otherwise that row must fail and use the retarded parameterization for physical acceptance. Join tolerances are explicitly supplied (angle 1e-12 rad, angular rate 1e-12 rad/s, angular acceleration 1e-12 rad/s²; position 1e-6 m, velocity 1e-8 m/s, acceleration 1e-10 m/s²), constrained further by source certificates. No mechanical high-limit fiction is used for electronic terminals. All source-body/attitude/frame fields are explicit.

Further behavioral parameterizations, all through public artifact ABI:

- **Presence and enums:** omit BODY_INDEX/NODE_INDEX/PROFILE_INDEX/OWNER_INDEX; compare explicit zero. Omit every applicable mechanical/control limit and compare valid explicit zero duration. Packed index HAS_VALUE=false is invalid even at value0. Unknown direction, steering, capability, nested shape enum, timing and result scope fail. Required tolerance omission never applies a hidden default.
- **Direction:** use a TX-only A and RX-only B; A_TO_B succeeds, B_TO_A/duplex have no compatible pair (explicitly empty success, not a false reverse service). Retarded lunar relay directional occultation edges are offset by twice the one-way delay on the station clock; preserve separate directed intervals. CSR carries only outgoing source arcs.
- **Schema/body:** omitted body errors; new op3 Moon sent to the archived deployed artifact returns unsupported rather than Earth windows. Archived op1 must be converted by acw-explicit-earth-v1 before new runtime use. Explicit Earth regression fields match archived correct results; events/access agree; observation-simulator op4 Moon rejects before EOP/shadow. Missing or different body echo fails requester validation. No live legacy path is retained.
- **Provenance/identity:** host stamps PVN after loading the exact artifact; all hashes are hex strings. Root with/without transport size prefix yields the same defined reference hash after prefix removal. Extended REC extracts EXTENDED_VALUE; reject a legacy union without standalone original. SIT uses its actual ID field when present, else explicit root-digest identity; no field named SITE_ID or name-derived identifier is invented. Corruption/dropped PVN fails.
- **Ordering:** force chunk boundaries around equal-time release/acquire, verify transition-before-snapshot rule, exact link deduplication across re-acquisition, pair/link numbering and global indices. Optional events off still produces requested and mandatory topology snapshots; on adds tagged non-topology extras, with equal epochs preferring REQUESTED. Missing chunk fails durable acceptance.
- **Year and quaternions:** split a 365-day interval into eight ≤4,000,000 s definitions with source halos inside the <2^22 bound; one unsegmented year rejects. Test q versus −q sign continuity on normalized rotations, duration-scaled derivatives and each supplied join tolerance; unbounded norm or a real attitude discontinuity fails.
- **Scheduling:** a three-node shared-slot case with equal proposals selects by terminal IDs; blackout overrides hold; acquisition/drain use capacity before/after ACTIVE; no scene link appears before ACTIVE. Multiple slots are checked explicitly. Determinism compares graph payloads at1/2/4/8 threads; host execution metadata is excluded.

## 7. Reference and consumer cases

These cases parameterize the public-artifact acceptance test. Closed-form arithmetic witnesses require an independent implementation and do not establish module validation. The reference-generator step requires independent oracle vectors before any physical comparison. Its own-body vectors cover finite-segment minima and endpoint/interior tangency for spheres and triaxial ellipsoids, with the explicit height≤0 supporting-plane convention tested separately. Orekit static oblate/spherical calculations and high-precision triaxial geometry provide the planned independent reference; tangent angles alone cannot decide finite-link visibility. Moving clocks use the solved null-line equations below. FPC path expectations use the existing solver and exact finite graph costs, not a new routing implementation.
