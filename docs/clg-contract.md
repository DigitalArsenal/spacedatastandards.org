# Constellation Link Graph contract

This contract defines an explicit-body `$ACW` and a new `$CLG`: geometric terminal feasibility, directed or bidirectional capacity-constrained service, and adjacency. It does not calculate RF/optical power, traffic or detection probability. The schemas specify serialization and consumer requirements; they do not implement geometry.

## 1. Explicit-body ACW and archive conversion

Existing fields, defaults and enum ordinals are unchanged. Append operation **3 COMPUTE_ACCESS_WINDOWS_EXPLICIT_BODY**, operation **4 SIMULATE_OBSERVATIONS_EXPLICIT_BODY**, and root slot **2 CENTRAL_BODY:BodyDescriptor**. New runtime access accepts only 3; new simulation accepts only 4. Both require a valid body. Missing body fails `acw-body-required` before geometry; archival operations 1/2 fail `acw-operation-retired`. Unknown operations fail unsupported. A valid body with a wrong operation is never processed.

This is an in-band safety gate: deployed access rejects operations other than 1 at `analysis/access/src/access_plugin.cpp:1376`; deployed observation-simulator requires 2 at `src/observation_simulator.cpp:524–529`. Therefore old modules reject new Moon **and Earth** requests. Schema hashes in a manifest are not the safety mechanism. All updated producers, including estimation fixtures and engine adapters, emit 3/4. Remove the replaced Earth-only C ABI and adapters in the coordinated consumer change; no parallel runtime geometry or default Earth constructor remains.

All target, observer, station, Sun and Moon states are interpreted in the descriptor's named fixed frame. `MOON_STATES` still names actual Moon 301. `EARTH_ORIENTATION` remains Earth-specific. Success echoes CENTRAL_BODY without modification, including optional presence, scalar bit patterns, strings and nested fields. Requesters compare every field recursively and reject absent/different echoes as `acw-body-echo-mismatch`. This is byte-for-byte comparison of field contents, not equality of relocatable FlatBuffer table/vtable offsets. Unknown descriptor fields require a supported schema reader or fail; they cannot be dropped during echo. Semantic failures echo a supplied structurally valid descriptor; missing/malformed input cannot produce a successful result.

There is one parameterized native geometry path. Explicit Earth uses axes `6378137,6378137,6356752.314245179` meters and a declared fixed-frame realization. For X=Y, that same parameterized function can use the algebraically specialized oblate formula with the existing operation order for regression equivalence; this is shape specialization for every oblate body, never a legacy/body-absent branch. Regression compares unchanged legacy numeric fields, not whole result bytes (the new envelope and operation differ). Deliberate station fixes have new expected values and are not claimed byte-identical to buggy cases.

Stored records without a body must first pass the named one-time offline conversion **`acw-explicit-earth-v1`**, owned by the ACW landing step. It writes Earth 399, the historical WGS-84 axes, an explicitly named `ARCHIVED_EARTH_FIXED_UNSPECIFIED` frame realization/manifest, an explicit atmosphere assertion from the archived settings, and maps operations 1→3 and 2→4. It hashes original and converted bytes in an audit manifest, processes requests and stored results, and is idempotent only after checking an existing matching descriptor. It never invents an ITRF edition or EOP coverage. Cross-frame use of the unspecified realization fails without authoritative metadata. A record whose original semantics cannot be established is quarantined with an error. Normal readers refuse unconverted bytes; the converter is not a runtime reader fallback. This conversion is an offline operation.

Every current ACW consumer is covered: **analysis/access**, **propagator/events** (embedded access implementation), and **analysis/observation-simulator**. Simulation's initial body-aware release supports explicit Earth only and fails `acw-body-unsupported` for 301/499/other bodies before `loadEop` or `kEarthRadius` shadow computation. Earth is validated against that implemented Earth model; arbitrary Earth axes/models also fail without an implemented parameterized model. No module may silently accept a body it cannot implement. Consumers in tests and the engine are updated with their producer operations in the same delivery sequence.

## 2. Shared body and record identity

`BodyDescriptor`, declared once in the ACW schema and reused by CLG, contains physical NAIF ID, body-centered fixed `RFMCoordinateSystem`, ordered X/Y/Z semiaxes in meters, shape/orientation model ID and manifest hash, explicit atmosphere model (`NONE` is allowed), optional terrain reference, optional gravity reference, and optional named spherical lighting model. Axes must be finite positive; a barycenter is not a physical body. The gravity reference radius never supplies the surface radius. Hashes everywhere use **64 lowercase hexadecimal characters**, following `$PVN`.

This shared table supplies information missing from existing body tables rather than competing interpretations. Map SCVEllipsoid BODY/NAME/FRAME to a resolved NAIF/frame realization; for a declared X-major/Y-intermediate/Z-minor convention map `SEMI_MAJOR_M→X`, `SEMI_INTERMEDIATE_M→Y`, `SEMI_MINOR_M→Z`. If that orientation is not known, refuse the mapping; never sort radii. An oblate source requires an explicit X=Y mapping. For DTT, resolve `CENTER_NAME`; map one `REFERENCE_RADII_M` radius to (r,r,r), two equatorial/polar radii to (a,a,c), and three to the declared longitude-0/east-90/polar X/Y/Z order. Retain tiling scheme, vertical datum and model/coverage manifest. A legacy DTT with omitted center/radii is not a source for an inferred body: require an explicit matching BodyDescriptor and an audited model manifest identifying its historical Earth/WGS-84 meaning, otherwise reject. Planetocentric DTT/SIT latitude is converted natively; it is not geodetic latitude. Terrain/geoid heights require their declared datum conversion. The shared TERRAIN reference points at DTT or a MODEL manifest of its tiles and certified native queries; GRAVITY references SHC or its manifest. Atmosphere `NONE` is a supplied assertion, never inferred from absent rendering data.

Geodetic latitude and longitude specify unit outward ellipsoid normal n. For axes a_i, the surface point is `s_i=a_i² n_i/sqrt(sum(a_j² n_j²))`, and height h yields `s+h*n`. Negative h is valid. The station retains n even when below the reference ellipsoid; it is not recomputed as the gradient at the displaced point. Triaxial shapes are supported and have a closed-form acceptance case in [validation](clg-validation.md).

Record references use `STANDARD` exactly as **REC.standard**, e.g. `CAT`, `SIT`, `OEM`, `CLG` (no dollar sign); `MODEL` denotes a manifest. SHA256 hashes exact standalone root bytes **without the four-byte size prefix and with the file identifier**. MODEL hashes exact supplied bytes with no JSON reformatting. Extended REC records use their exact `EXTENDED_VALUE` root bytes; reject missing identifiers or a mismatched standard. Legacy REC union payloads must arrive with their separately supplied standalone original root bytes; this version refuses hashing a reconstructed union table or whole REC as that root.

`RECORD_ID` has this normative selector meaning: `root` selects the whole root for any supported standard; `CAT:OBJECT_ID=<percent-encoded exact OBJECT_ID>` selects that catalog object; `CMR:MEMBERSHIP_ID=<percent-encoded exact MEMBERSHIP_ID>` selects the membership root; `CMR:OBJECT_ID=<...>` selects a root whose OBJECT_ID matches, when supplied. Empty or nonunique IDs cannot use these selectors. For SIT use `SIT:ID=<percent-encoded exact ID>` when its actual `ID` field (documented BE_NUMBER) is present; validate exact equality. When it is absent use `root` plus the exact content digest, with no fabricated identifier or name-based join. The schema has no field literally named SITE_ID. AEM/ACM/OEM with several segments use `root` and the named source's declared segment selection in its interpolation manifest; ambiguity fails. Additional selector grammars require an implemented standard-specific reader. Node joins within a graph use `(GRAPH_ID,NODE_ID)`, terminal joins `(GRAPH_ID,TERMINAL_ID)`, pair joins `(GRAPH_ID,PAIR_INDEX)` including direction. Cross-record content identity is `(STANDARD,SHA256,RECORD_ID)`; cross-revision object identity requires the explicit CAT/CMR key or a supplied identity mapping. A hash change alone never silently joins revisions. URI is advisory; the module fetches nothing.

GRAPH_ID is globally unique across producers and stores that exchange CLG records, not merely within a request, process, producer, or chunk set. It names one immutable node dictionary forever. A store atomically binds a new GRAPH_ID to the accepted definition's SHA256 and dictionary; every record presenting a known GRAPH_ID must resolve to that same definition hash. A different definition hash is rejected as `clg-graph-id-conflict`, never merged or rebound, even if the node dictionary is unchanged. Deleting result chunks does not release the identifier for reuse. Changed definitions require new identifiers. Definition hashes retain the exact standalone-root byte rule above.

A hash-derived GRAPH_ID is recommended, not required. To avoid hashing an identifier into itself, a producer can derive the identifier from a documented canonical encoding of the definition content with GRAPH_ID excluded, then hash the complete serialized definition for the store binding. This derivation digest does not replace the exact-root definition hash. A producer choosing its own identifier must guarantee global uniqueness and permanent non-reuse across independent producers, restarts, exports and stores; a local counter or unqualified name alone supplies no such guarantee. The store rejection rule applies to both identifier strategies.

Reuse OMM/OCM mean-element theory, OEM/OCM trajectories, PCF/PRW force configuration, SHC/NCD model identity, RFM/FRM coordinates, AEM/ACM attitude, SIT/TBS sites, SNR/SCV shape, and RFB/PAP/BEM reviewed PHY definitions. TBS and SGP4 remain Earth-specific. CLG is not ACI link-budget threshold output; RFL/ACI/LKS can join it by explicit graph/terminal IDs. Append CLG to extended REC ordinals (296 only if it is the first available ordinal), not the full byte union. SDS tooling generates headers and all bindings.

## 3. Presence, time, frames and attitude

Every table scalar declared in ACW and CLG, including enums and booleans, has an appended `HAS_<FIELD>:bool=false`. The flag is the sole presence test: false means omitted regardless of stored value; true means supplied and subject to domain validation. Explicit zero/false has a true flag even when FlatBuffers elides the value slot. Retained NaN/−1/old ACW defaults are wire defaults, never presence or runtime defaults. `HAS=true` with NaN or an invalid index fails. Conditional fields are absent when inapplicable; required applicable flags must be true. `MOTION_SOURCE_INDEX` may be absent only with explicitly present `FRAME_STATIONARY=true` and verified identical fixed working frame. Epoch days are nonnegative. The exhaustive field inventory in [scalar presence](clg-scalar-presence.md) is normative and audited against both files; optional-scalar `= null` syntax is prohibited.

Packed indices use `CLGIndex {VALUE,HAS_VALUE}`. Packed numeric groups use `HAS_VALUES`, blackout times `HAS_TIMES`, transition time `HAS_TIME`, and optional readiness `HAS_READY_FROM`; pair/cause/transition enums have individual flags. Vector/quaternion structs require their containing pointer and `HAS_VALUES=true`; components form one supplied tuple. A false required bit fails even when stored bytes look valid. Flags themselves are presence metadata: omitted and explicit false both encode absence, not a supplied domain value, and do not recursively need flags. Scalar-vector entries are atomic supplied elements; the vector pointer establishes presence, and each present element, including zero, is explicit. Required vectors may be empty only where specified. No valid all-zero quaternion exists.

For explicit-body ACW operations 3/4, all applicable scalar fields in the entire ACW family require these flags, including inherited state samples, masks, sensor controls, constraints and successful outputs. Optional override, signature/identity, and conditional diagnostic fields remain absent unless supplied/applicable; no zero-value enable/disable convention substitutes for presence. Required quantities with historical wire defaults (e.g. ROOT_TOLERANCE_S, refraction pressure, sensor capacity) require a true flag and valid explicit value. The archive converter materializes each established historical input/default with its flag and quarantines ambiguous records. Old operation dispatch still refuses 3/4 before these semantics apply. Reused external tables retain their own standard's presence rules; required nested physical data must be explicit in its supplied record/manifest or fail.

Every new CLG enumeration has UNSPECIFIED=0, invalid when applicable even with a true presence flag. This rule is scoped to the CLG enumerations. Existing ACW values are unchanged: acwResultStatus.OK, acwRefractionModelKind.NONE, acwConstraintOperator.ALL_OF, acwEvaluationMode.DISCRETE and acwLightingCondition.ANY are legitimate zero values with their respective true HAS flags. acwOperationCode.UNKNOWN=0 is invalid for execution; operations 1/2 require archive conversion and operations 3/4 select explicit-body execution. acwConstraintKind.UNSPECIFIED=0 and acwSensorPhenomenology.UNSPECIFIED=0 are invalid when applicable. [scalar presence](clg-scalar-presence.md) lists every ACW enum field, its flag and its domain. False flags mean absent even for legal zero values; applicable required fields cannot be absent. Readers validate **every enum including nested reused schemas** against its own declared domain, and fail `clg-enum-unsupported` or `clg-scope-unsupported` on any value/scope they do not implement. They resolve the definition before accepting a result, and verify per-chunk TIMING/ANALYSIS_SCOPE. They cannot read a directed chunk as an undirected graph.

For ACWAccessWindow, a start or end clipped to the sample span has no limiting constraint: its corresponding HAS_START_LIMITING_CONSTRAINT_INDEX or HAS_END_LIMITING_CONSTRAINT_INDEX is false and its limiting label is absent. A present index is nonnegative and within the flattened depth-first constraint list. The retained wire default is not a clipping sentinel. The archive converter represents established clipped boundaries with absent indices and validates attributed indices before setting their flags.

Time is two-part noon-based JD TT: integer day and seconds [0,86400). Every offset, including source coverage halos and receive tails, has absolute value **<2^22 s**. Longer analyses, including a year, use separately re-epoched definitions with distinct graph IDs. Never combine JD into one double for event arithmetic. Effective isolation floor is max(user floor, 2*ulp(offset)); if it prevents separation or requested accuracy, fail `clg-time-resolution`. At this cap binary64 ulp is below 0.466 ns, retaining explicit 1 ns floors. Light time is evaluated using local differences and the native frame/time manifest.

SIMULTANEOUS may use a named body-fixed working frame. RETARDED_VACUUM uses SSB/ICRF inertial coordinates or an explicitly defined constant-velocity, constant-axis Lorentz transformation of them. A body-centered inertial approximation (e.g. GCRS-like) is accepted only with a named origin worldline/time mapping and certified error sufficient for the requested accuracy; a freely accelerating body-center frame is not silently treated as a straight-ray inertial frame. Rotating fixed frames are rejected for retarded ray solving. Native foundation/frames converts all inputs consistently; no addition of unrelated local positions.

Every spacecraft explicitly chooses **SUPPLIED_SERIES**, **NADIR_LVLH**, or **INERTIALLY_FIXED**. SUPPLIED_SERIES normalizes polynomial Q and evaluates exact derivatives. NADIR_LVLH uses body-relative r,v from the same state interpolant: Z=−r/|r|, Y=−(r×v)/|r×v|, X=Y×Z (transverse prograde, coinciding with velocity only for circular motion). Derivatives through second rotation order use exact p/v/a/jerk from that interpolant; degenerate radius/angular momentum fails. INERTIALLY_FIXED supplies a unit quaternion and explicit inertial frame. No engine/host inference supplies attitude. Source residuals for LVLH include jerk and are propagated through the normalized triad.

In retarded mode quaternion R specifies physical node axes in the rotation-free instantaneous rest-frame convention relative to the working inertial axes. Construct U and spatial tetrad columns as `U=B(v/c)(1,0,0,0)` and `e_i=B(v/c)(0,R[:,i])`, where B is the standard Lorentz boost from rest to working coordinates. An exact inertial-frame change transforms U and e_i together and re-extracts the quaternion (including any Wigner rotation); reusing the old quaternion after a boost is invalid.

Stations use **STATION_ENU**: +Z=n, +X=east=normalize(k×n), +Y=n×east, where k is fixed-frame +Z. At either exact pole east is fixed-frame +Y and north=n×east. This convention fixes mounting even when longitude is geometrically degenerate; no epsilon band changes it. SITE_UP is the supplied ellipsoid normal, checked against the geodetic source. MOUNT_TO_NODE is active Hamilton xyzw from mount axes to these node axes; station identity mount points at zenith.

Pose segments are degree 0..7 normalized-time polynomials. Continuity is checked on **normalized rotation**, with q and −q equivalent. Producers choose sign-continuous representatives at each join (dot>0); zero dot or zero norm fails. Validate geodesic rotation difference and angular velocity/acceleration differences against explicit ATTITUDE/RATE/ACCELERATION_JOIN tolerances; also validate p/v/a joins. Derivatives include duration scaling. These tolerances must fit the source/error budget and are never permission for a physical maneuver jump; split such a jump into a new definition. Exact law attitudes use derivatives directly, not sampled quaternion fitting outside the module.

## 3a. Interval and snapshot clocks

Every `_S` epoch/offset in CLG is seconds from the definition's two-part **TT** epoch unless explicitly labeled a duration or error bound. TT is an event label: native frame/time mapping converts it to the declared inertial coordinate time for null-ray solving. LIGHT_TIMES_S measures coordinate vacuum flight duration, not a host subtraction of TT labels. Local endpoint time means the TT label of that endpoint event, not an unspecified proper clock.

| Field or rule | SIMULTANEOUS | RETARDED_VACUUM |
|---|---|---|
| Definition START/STOP, interval START/STOP/READY_FROM, boundary OFFSET/BRACKET, decision grid | Same-epoch geometry query q | Common **emission** query q; both demanded duplex rays emit at q, with generally different reception epochs |
| CLGBoundary.RAY_TIMES | One record per demanded direction, emission=reception=q, mapped bracket equals boundary bracket | Each record carries emission q, directional reception r(q), and certified reception bracket mapped from the entire emission bracket plus solve error |
| Blackout START/STOP | Endpoint event q | Actual local emission or reception event; receiver blackout is pulled back through r(q) before emission-interval isolation |
| Source poses and state knots | TT sample events | TT worldline events, with all past/future coverage required by rays and pointing |
| Transition TIME | Actual reservation/control event; ACTIVE/RELEASE delimit emission service | Actual reservation/control event; ACTIVE/DRAIN delimit emission service, RELEASE is latest required reception after DRAIN |
| Adjacency EPOCH and topology-change epochs | Emission/geometry query q after all equal-time transitions | Emission query q after all equal-time transitions; an arc exists iff a photon may be emitted at q |
| Per-arc RANGES/LIGHT_TIMES/RECEPTION_EPOCHS | Same-epoch distance, distance/c estimate, reception label q (no modeled travel) | Directional null-ray length, coordinate flight duration, reception TT r(q), all computed in the module |

CLGInterval is a maximal common-emission feasible span. A duplex interval is the intersection of the two directed feasible sets in q, not an intersection of an uplink emission interval and a downlink reception interval. Both start and stop boundaries are pair-specific (`PAIR_INDEX`), with exactly the demanded ray records in A_TO_B/B_TO_A order. Do not reuse a boundary across pairs merely because their emission roots coincide; reception times differ. Range extrema cover both demanded path lengths over q. At a common-axis terminal evaluate incoming/outgoing bearings at each actual local event using the same covered worldlines; derivatives, blackouts and drain reservations use their actual local epochs. READY_FROM is a candidate emission-ready epoch; scheduling determines actual ACTIVE.

Boundary roots/brackets, all co-causes and topology events use q. A receive-side root is mapped back to q; CAUSES.DIRECTION identifies its photon direction. The open end of [START,STOP) has the limiting reception r(STOP) recorded, even though no photon is emitted exactly at STOP. Geometric thresholds are closed; positive-duration service is half-open. RETARDED DRAIN removes both duplex emission arcs at q_stop; slots remain reserved through `max(r_AB(q_stop),r_BA(q_stop))`. Equal-time updates are atomic. In simultaneous mode no reception tail or drain is invented even though distance/c is available as a routing cost estimate.

## 4. Visibility, direction, hardware and accuracy

All applicable ranges are finite meters with 0≤MIN_RANGE_M<MAX_RANGE_M and positive maximum; rates are radians/s and accelerations radians/s². Elevation limits lie in [−π/2,π/2]; point-ahead limits lie in [0,π], with the stricter positive retarded common-axis rule below. Requested accuracy, solver tolerances, decision step and thread count are positive; hold/active times, residuals and join tolerances are nonnegative. Every position coefficient is finite, each degree is an integer0..7, each segment has start<stop, and every applicable index is within the referenced dictionary. In retarded mode all terminal speeds in the declared inertial model are finite and strictly below c. SCV angles retain degrees and are converted natively. Terminal positions coincide with their nodes in this version. BODIES must enumerate all physical occultors relevant to the declared model; coverage and source provenance are required for each.

**Station-own-body rule (ACW and CLG):** the user's elevation mask remains a separate constraint, `e >= MIN_ELEVATION_RAD`, measured above the local horizon plane using the specified geometric/apparent bearing. Height h is the signed normal distance from the source ellipsoid foot point, not distance from the body center. Own-body clearance has two cases:

- **h>0:** the link is blocked by the reference ellipsoid exactly when the finite segment from the station to the other endpoint passes through its interior. Tangent contact, including endpoint-only contact, is not blocking. A segment ending before the first interior penetration is clear even when directed below the infinite-ray tangent horizon, provided the user mask permits it. No unconditional tangent-elevation cutoff applies.
- **h≤0, including exactly zero:** no intersection test against the station's own ellipsoid applies. The supporting-plane rule uses the retained outward normal n and requires the target bearing to satisfy `e >= max(MIN_ELEVATION_RAD,0)`. This is the above-horizon convention at the physical station with the plane parallel to the foot-point tangent plane; equality is geometric contact and is allowed. It prevents own-body self-blockage for zero/negative heights. It does not exempt spacecraft from body clearance.

For a static ellipsoid and h>0, express station p and target x in its centered fixed axes, set `d=x−p`, `A=sum(d_i²/a_i²)`, `B=sum(p_i*d_i/a_i²)`, `C=sum(p_i²/a_i²)−1`, and `s=clamp(−B/A,0,1)`. Coincident endpoints fail. The finite segment is clear exactly when `A*s²+2*B*s+C >= 0`; a negative value means interior penetration. At zero discriminant a tangent has no interior penetration. The static spherical tangent angle `−acos(R/(R+h))` describes an infinite ray, not a finite-link cutoff. Apply the appropriate height case at each station endpoint of a station-station pair.

In retarded mode the h>0 test uses the finite photon flight and the body's true ellipsoid at each flight event, with the same native worldline/frame model as the other occultors. A surface intersection beyond the receiving endpoint is irrelevant. The h≤0 supporting-plane convention uses the station's emission/reception event and local apparent target bearing. Missing certified own-body clearance bounds fail `clg-horizon-unresolved`.

Stations require ELEVATION_GATE=MIN_ELEVATION; spacecraft require NONE with angle absent. Other bodies still occult the full finite ray. Supplied terrain is an additional constraint at every height: test the actual finite flight ray from the physical site against its certified datum-aware surface, allowing contact and rejecting interior penetration. Missing coverage fails. Own-body and terrain crossings have separate HORIZON_A/B and TERRAIN_A/B causes; BODY_INDEX is supplied for these and OCCULTATION, absent for other causes. The user elevation constraint retains its separate ELEVATION cause.

**Space-to-space clearance:** BodyDescriptor keeps its true axes. CLGBody.SPACE_SPACE_SKIM_MARGIN_M, explicitly finite nonnegative, inflates each axis only when both endpoints are spacecraft. Any pair containing a station uses zero margin for every occultor. ACW's existing OCCULTATION_ATMOSPHERE_HEIGHT_M has the same pair-class rule and axis-addition wording. Axis offset is not constant geodetic altitude. Spacecraft embedded in an applicable occultor are blocked; the station exemption is never generalized to spacecraft.

A and B are endpoint identities ordered by exact unsigned UTF-8 byte tuples `(NODE_ID,TERMINAL_ID)`, ascending; IDs are nonempty, unique in their dictionaries, and receive no locale sorting or implicit Unicode normalization. Definition NODES is sorted by NODE_ID; its vector position is the dense node index 0..N−1. TERMINALS is sorted by `(NODE_INDEX,TERMINAL_ID)`, so for distinct nodes A's terminal index is always smaller. These dictionaries are immutable across every state block, chunk and snapshot of one GRAPH_ID, including isolated nodes. No sorting, pruning or renumbering is permitted after acceptance. Unsorted input, reversed pair endpoints, duplicate IDs and out-of-range indices fail `clg-noncanonical-order`; a producer canonicalizes before serialization and remaps every index together. Thus A_TO_B always names the same transmitter under arbitrary pre-serialization input permutations. CLGPair carries both canonical terminal indices and explicit direction; its referenced definition supplies the exact identities.

CONTROLS.DIRECTION requests BIDIRECTIONAL, A_TO_B or B_TO_A relative to those identities; one-way analyses in the other direction use separate requests. TRANSMIT/RECEIVE capabilities gate the demanded rays. Duplex requires both directions; A_TO_B requires A transmit/B receive, and B_TO_A reverses that. Never silently downgrade duplex. COMPATIBILITY_CLASS and medium must match. Pairs sort by `(TERMINAL_A,TERMINAL_B,DIRECTION)`; direction is part of identity.

Hardware has three classes:

- **MECHANICAL:** finite positive rate, acceleration and acquisition-rate ceilings (acquisition rate ≤ tracking rate), explicit nonnegative settle/acquisition times, explicit initial direction at rest. Rate and acceleration leaves and certified slew/acquisition reservations apply. Zero rate is invalid, not a fixed-beam encoding.
- **FIXED_BEAM:** boresight fixed at mount +Z; regard-only pointing feasibility. Mechanical fields must be absent; no SLEW/ACQUIRE transition and no tracking-rate gate. A moving target crossing a fixed cone is visible throughout that crossing.
- **ELECTRONIC:** regard-only pointing feasibility; mechanical fields absent. Optional BEAM_SWITCH_TIME_S is distinguished from explicit zero by HAS_BEAM_SWITCH_TIME_S=false; omission requests no modeled switch delay, and the result retains that model choice through its definition. A nonzero delay reserves the slot in ACQUIRE before ACTIVE. No fictional gimbal rate.

Capacity is positive at node and terminal; multiple slots require INDEPENDENT_BEAMS=true. FIXED_BEAM multiple slots share its fixed boresight and do not gain steerable axes. Each service occupies one slot at each endpoint even for one-way reception. No pre-acquired service is inferred.

COMMON_AXIS compares incoming/outgoing apparent bearings at a common local endpoint epoch. In retarded mode its MAX_POINT_AHEAD_RAD must be finite **positive and explicitly supplied**, including a supporting beam/capture definition reference; otherwise `clg-point-ahead-tolerance-required`. This validation also applies to a common-axis profile used in a one-way request, though no unrequested second ray is tested. SPLIT_TX_RX has independent paths and its own explicit finite separation limit. For duplex common-axis feasibility each apparent bearing must fit the regard/beam and their separation must meet the supplied tolerance; the tracked mechanical axis is their normalized bisector, with the supporting reference specifying allowable off-axis offsets. Split paths each satisfy mechanics. One-way uses only the demanded bearing. Simultaneous duplex may explicitly state zero separation tolerance.

Retarded pointing **includes observer aberration**; The local tetrad convention in section 3 defines the required Lorentz transformation. Point-ahead to first order is `2(vB−vA)_perp/c`, not `2vB_perp/c`. Spacecraft/station attitudes, elevation, field of regard and derivatives all use those local apparent bearings.

Every COMPLETE chunk has numerical, source, frame/time and **model** error bounds. SIMULTANEOUS model error is at least `Rmax/c`, where Rmax is the maximum supported min(endpoint max ranges) over the requested compatible pair classes, not just the largest observed accepted edge. Additionally certify the model-to-retarded event discrepancy using leaf perturbation/slope bounds; near a graze Rmax/c alone is not necessarily sufficient. Unknown/unbounded discrepancy fails. Reject if the sum of certified errors exceeds REQUESTED_TIME_ACCURACY_S. Requests with potential endpoints on different bodies always reject simultaneous mode (`clg-simultaneous-interbody`), even if that pair later fails LOS. Thus 1,500 km and 1 ms requested physical timing cannot pass simultaneous mode (the floor alone is 5.00346 ms). Retarded vacuum bounds are conditioned on the named vacuum/ephemeris model; requested refraction, group delay or relativity not implemented fails rather than masquerading as vacuum truth.

Intervals are maximal positive-duration feasible spans; a zero-duration tangent is not service. Geometric boundaries use closed inequalities; ACTIVE uses [start,stop). Range extrema include endpoints and all stationary points of each demanded directional path. READY_FROM exists only if class-specific acquisition can finish, assumes already-on-target start, and is not actual schedule readiness. Every boundary has a vector of all causal `(kind,ray direction,body)` tuples, sorted by enum ordinal then direction then body. Overlapping certified brackets trigger refinement: prove a shared event and retain all causes, or separate the brackets; unresolved overlap fails. Never tolerance-merge distinct roots. Span clipping is a cause too.

The deterministic retain-then-greedy policy is maximal only among that decision pass's fixed certified proposals; it is not an optimal matching or a connectivity guarantee. Transitions are authoritative between snapshots. Retarded transmit-stop removes CSR arcs and enters DRAIN; slots stay reserved through the last demanded photon arrival. No slew/retargeting during drain. Simultaneous mode releases directly.

## 5. Provenance, ordering and bounded streaming

Module-written CLGProvenance contains only what the module knows: definition digest, a vector of state-block hexadecimal digests in sequence order, algorithm, scope, timing and error bounds. **PVN on CLGResult carries producer identity**. The host that loaded the artifact writes PRODUCER and PRODUCER_SHA256 using the existing convention (exact loaded dist/module.wasm bytes). The guest never embeds its own hash or a placeholder. A host finalization stage reconstructs each unpublished result buffer to attach PVN, validates it, and only then hashes/publishes immutable COMPLETE chunks; spool quota includes this bounded reconstruction. Module bytes and host-finalized bytes are distinct documented stages. No native physics is repeated by the host.

Chunk indices start at 0, count is positive, every chunk repeats scope/timing/provenance and resolves the same immutable definition. PAIRS and LINKS occur only in chunk 0. Links are deduplicated by `(PAIR_INDEX,SLOT_A,SLOT_B)` across re-acquisitions, numbered by `(first transition time,PAIR_INDEX,SLOT_A,SLOT_B)`. No time-linear dictionary growth is assumed. The combined encoded dictionary frame limit is 64 MiB; excess fails `clg-dictionary-too-large`, never pruning. Intervals are ordered `(start,pair,stop)` and occur once, with local boundary indices referencing BOUNDARIES in their chunk; a boundary may be reused only for the same pair, emission event and directional reception maps.

Transitions are globally sorted `(TIME_S,stage rank,LINK_INDEX)`, with **RELEASE<DRAIN<SLEW<ACQUIRE<ACTIVE** independent of enum wire ordinals. A zero-duration control phase is collapsed before emission; one link cannot drain and release at the same instant. Apply all equal-time transitions atomically before an adjacency snapshot. Each transition appears once. Every transition at or before a chunk's final adjacency epoch must be in that chunk or an earlier chunk. If it does not fit, emit preceding transition-only chunks. No later chunk introduces an earlier transition. Adjacencies have strictly increasing epochs globally, rows sorted `(neighbor,link)`, N+1 offsets and no self arcs. A_TO_B has one outgoing A-row arc, B_TO_A one B-row arc, bidirectional two. Arc direction follows the pair; no receive-only row is invented.

Requested snapshots have ORIGIN=REQUESTED. Every COMPLETE result carries a present TOPOLOGY_CHANGE_EPOCHS_S vector per chunk (empty allowed): its global concatenation is sorted unique and contains START_OFFSET_S plus every epoch where the directed `(source,destination,LINK_INDEX)` multiset changes after atomic transitions, including final removal at STOP if nonempty. Each listed epoch has a mandatory post-update adjacency, even when EMIT_EVENT_SNAPSHOTS=false. Those snapshots have ORIGIN=TOPOLOGY unless also requested. Additional non-topology control-event snapshots require explicit EMIT_EVENT_SNAPSHOTS=true and have ORIGIN=EVENT. Deduplicate epochs with priority REQUESTED > TOPOLOGY > EVENT; membership in the change vector is preserved. Report mandatory topology and optional event counts/bytes separately. No SLEW/ACQUIRE/RELEASE event that leaves the active arc multiset unchanged is a topology change.

All three per-arc scalar vectors have exactly the arc count, finite positive ranges/light times, and valid reception epochs; they are produced by native geometry, never reconstructed from states by a consumer. Duplicate parallel terminal links retain separate arcs/link indices. Empty successful graphs retain all N nodes, N+1 zero row offsets, present empty metric vectors, and an initial topology snapshot. Failed/cancelled jobs expose no truncated COMPLETE set. Durable acceptance requires all chunks, definition and host provenance.

## 7. Normative FPC routing consumer

Inputs are an accepted complete CLG result/definition, a selected adjacency epoch, a cost choice and source/target node indices. Output is exactly one existing `$FPC` directed graph: `FPCGraphDefinition.VERTEX_COUNT=N`, with either `FPCCSRGraph` or `FPCWeightedEdgeList`. Copy CLG ROW_OFFSETS to OFFSETS, NEIGHBOR_NODE_INDEXES to DESTINATIONS, and the selected weights to WEIGHTS. For edge-list form, CSR row i supplies SRC=i, its neighbor supplies DST, and the selected weight supplies WEIGHT. No routing schema or solver is added to CLG.

For **quickest path**, copy LIGHT_TIMES_S in seconds; this minimizes the sum of snapshot vacuum propagation delays. For **fewest hops**, use weight 1 for every arc. Each one-way service contributes exactly its one outgoing arc; duplex contributes two independently weighted arcs. Retain parallel links and keep the arc-to-LINK_INDEX mapping outside FPC for display; FPC path vertices alone do not identify which parallel terminal link was used. Isolated nodes remain vertices with empty rows. Call the existing FPC single-source request with an explicitly selected supported solver, then its path request; unreachable results retain FPC's infinity/UINT32_MAX/unreachable semantics. No geometry, range/c, frame conversion or retarded solve runs in the adapter.

For an **interval topology route**, solve at its initial selected snapshot and once at each later TOPOLOGY_CHANGE_EPOCHS_S within the interval, using the mandatory change snapshot, and hold that route through the following topology interval. Fewest-hop optimality persists while topology is constant. Quickest-path weights are explicitly sampled and held at the solve epoch; this result is a snapshot-cost route, not a guarantee of continuous quickest routing or end-to-end packet arrival. Delays can change and swap the optimal route without a topology change; continuous optimality or time-dependent store-and-forward routing requires a separately specified consumer policy. Requested metric snapshots may support explicit additional solves; none is driven implicitly by render frames.
